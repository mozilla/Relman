Bugzilla API key

The dashboard runs as you: with your key it sees exactly what your Bugzilla account sees, including the security bugs. Without one, security checks show needs key.

Create a key at Bugzilla → Preferences → API Keys.

Saved in this browser's local storage only, and sent only to bugzilla.mozilla.org. Bugzilla keys cannot be limited to reading, so create one just for this dashboard: you can then revoke it on its own.
